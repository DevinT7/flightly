# Flightly

An iOS (SwiftUI, iOS 17+) flight tracker modelled on Flighty, with every Pro feature unlocked. See [docs/EVIDENCE.md](docs/EVIDENCE.md).

```
brew install xcodegen   # once
xcodegen generate
open Flightly.xcodeproj
```
Live data is simulated (`Flightly/Data/LiveEngine.swift`). Settings → "Time machine" fast-forwards the clock to watch a flight play out.
